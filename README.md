## 部署与维护 / Deployment and maintenance

本项目通过 GitHub Pages 发布，使用 `main` 分支根目录。更新 `main` 分支后会自动构建并部署。
The site is hosted on GitHub Pages from the root of `main` and redeploys automatically when `main` is updated.

页面使用静态 HTML、CSS、JavaScript 和本地资源，无需后端或额外构建工具。支持中文、English、Русский、Français 和 العربية。

详细文件说明、维护方法及引文信息见 [README-部署说明.md](README-%E9%83%A8%E7%BD%B2%E8%AF%B4%E6%98%8E.md)。
